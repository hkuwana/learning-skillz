# Learning Skillz Playground 🚀

Welcome to the **Learning Skillz** playground! 

This repository is an experimental environment designed to explore interesting feedback loops, test agent skills (such as Matt Pocock's skills), and experiment with different git workflows and commit patterns.

## Purpose

- **Feedback Loops**: Test fast, interactive feedback loops using automated test runners, red-green-refactor loops (`/tdd`), linting, and AI-assisted workflows.
- **Skill Experimentation**: Experiment with custom and installed agent skills (e.g. `/grill-me`, `/to-spec`, `/implement`).
- **Git Playground**: Try out small, deliberate commits, branch strategies, and commit-based reviews.

## Getting Started

```bash
# Install dependencies
npm install

# Run tests in watch mode for rapid feedback
npm test
```
